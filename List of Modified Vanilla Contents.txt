# common/inline_scripts/shroud/psionic_aura_monthly_decrease.txt
#   Adds the mod's psionic inhibitor/burster logic to vanilla aura decay.
#   Inhibitor station in the current system: -75 monthly decrease.
#   Inhibitor station in a neighboring system: -50 monthly decrease.
#   Burster stations suppress both extra penalties.

# common/inline_scripts/shroud/aura_wide_modifiers.txt
#   Compatibility mirror of the v4.5 file. As of this review the gameplay
#   content is identical; the checked-in copy differs mainly in formatting.

#   85-frame Touhou ship-class icon sheets.

#   This is primarily a Linux/macOS rendering compatibility change.
