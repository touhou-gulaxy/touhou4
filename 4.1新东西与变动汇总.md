### 恐慌状态

```text
set_terrified_by - Sets which ship terrified the target ship/fleet (all ships). Clears at the end of combat.
set_terrified_by = <attacker>
Supported Scopes: ship fleet

remove_terrified - Removes terrified state on the target ship/fleet (all ships).
remove_terrified = yes
Supported Scopes: ship fleet
```

前者为设置舰船被某个舰船恐慌，后者为移除恐慌状态。

### 替换原版超主

先定义你的超主，然后使用如下的effect

```text
replace_patron - Replace a patron with another one, creating the patron relation if it does not yet exist, and setting the new patron to the replaced patron's position in the shroud plane.
replace_patron = { new_patron = <patron_key> replaced_patron = <patron_key> }
Supported Scopes: country

remove_patron - Remove a patron from the shroud plane.
remove_patron = <patron_key>
Supported Scopes: country
```

### 灵能光环相关操作

#### effects

```text
spawn_psionic_aura - Spawns a Psionic Aura in scoped system, where country is the aura's owner.
spawn_psionic_aura = { country = <country>
Supported Scopes: galactic_object

set_aura_intensity - Sets given intensity to Psionic Aura in scoped system
set_aura_intensity = <int>
Supported Scopes: galactic_object

add_aura_intensity - Adds value to Psionic Aura intensity in scoped system
add_aura_intensity = <int>
Supported Scopes: galactic_object

refresh_psionic_aura_type - Forces an Empire's Psionic Aura to immediately update its type
refresh_psionic_aura_type = yes
Supported Scopes: country
```

#### triggers

```text
has_psionic_aura - Check if the scoped system is affected by any, or a specific type, Psionic Aura.
has_psionic_aura = <yes/no>
Supported Scopes: galactic_object

has_patron_aura - Check if the scoped country has a psionic aura from given patron.
has_patron_aura = the_eater_of_worlds
Supported Scopes: country

has_patron_relation - Check if the scoped country has established a relation with given patron. The contact state can be specified (completed by default).
has_patron_relation = {
	patron = <patron_key / any>
	contact (optional) = <completed (default)/in_progress/none/any>
}
Supported Scopes: country

is_aura_intensity_level - Checks the Psionic Aura's intensity level inside the scoped system.
is_aura_intensity_level = 2
Supported Scopes: galactic_object
```

#### modifiers

```text
- psionic_aura_effectiveness_mult, Category: Countries
- psionic_aura_intensity_add, Category: Countries
- psionic_aura_intensity_mult, Category: Countries
- ship_psionic_aura_speed_mult, Category: Ships

```

### leader_tiers

定义方式:
```pdx
leader_tier_touhou = {
    tier = 3                        # 作用等同于之前的LeaderTierNumber
    texture_postfix = "_paragon"    # 作用等同于之前的LeaderTierTexturePostfix
}
```
想要显示为“幻想的存在 指挥官”这种，仍然需要覆盖ClassPrefix与ClassPrefixColor_FR
```pdx
defined_text = {
    name = ClassPrefix
    random = no
    text = {
        trigger = {
            is_leader_tier = leader_tier_touhou
        }
        localization_key = CLASS_PREFIX_TOUHOU
    }
    text = {
        trigger = {
            is_leader_tier = leader_tier_renowned
        }
        localization_key = CLASS_PREFIX_RENOWNED
    }
    text = {
        trigger = {
            is_leader_tier = leader_tier_legendary
        }
        localization_key = CLASS_PREFIX_LEGENDARY
    }
    default = CLASS_PREFIX_NONE
}
```

用法:
```pdx
set_leader_tier = leader_tier_touhou
if = {
    limit = { is_leader_tier = leader_tier_touhou }
}
```
